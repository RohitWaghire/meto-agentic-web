# Two-minute demo script

Record in a browser. Human voice. No copyrighted music. Under two minutes.

1. Open the Orra floor. “This is Orra, a dummy lighting shop. The agent runs in my browser, on my key.”
2. Expand AI model settings, paste the key, Save and start.
3. Show Permissions: spend cap $500, always_ask.
4. Ask: “Add the Arc Sconce and place a pickup order in my name.”
5. Show the timeline / tool calls, then the confirmation: items, total, rollback sentence. Click Place the order.
6. Cart empties, order received.
7. Click Undo run, confirm. Order refunded, timeline shows rolled back.
8. Ten seconds: “A second origin, Orra Freight, can be loaded after I allow it. Other agents register at /api/v1/agents/register. No card numbers ever go to the model.”
