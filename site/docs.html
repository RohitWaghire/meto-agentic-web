How meto lets an agent act

The agent network is data: agent-manifest.json and meto_concierge.network.json. The runtime in runtime/ runs it in your browser with the key you paste.

Writes go through the same App.page methods as the buttons. Irreversible tools open a dialog that names the rollback. Deny is a visible refusal, not a silent skip.

Other sites may fetch the public files (CORS). They do not receive your LLM key. meto Freight is a second origin — locally http://127.0.0.1:8081, and a public HTTPS host when deployed.

Inbound agents: POST /api/v1/agents/register then POST /mcp. Token-less callers may only read. checkout_agent answers HTTP 402 until PAYMENT-SIGNATURE: demo-usdc.
