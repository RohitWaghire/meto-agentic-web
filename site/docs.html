How Orra lets an agent act

The agent network is data: agent-manifest.json and orra_concierge.network.json. The runtime in runtime/ runs it in your browser with the key you paste.

Writes go through the same App.page methods as the buttons. Irreversible tools open a dialog that names the rollback. Deny is a visible refusal, not a silent skip.

Other sites may fetch the public files (CORS). They do not receive your LLM key. Orra Freight is a second origin on port 8081 during local demo.

Inbound agents: POST /api/v1/agents/register then POST /mcp. Token-less callers cannot checkout.
